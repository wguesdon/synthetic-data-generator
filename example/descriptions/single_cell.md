# Single-cell AnnData file

This is an example of a description that a user gives to the agent. Every name and number is invented.

The customer sent one AnnData file of 2,000 cells and 800 genes from two donors. X holds log-normalized values, and the `counts` layer holds the raw counts.

The obs table has a `donor` column with two donors, a `leiden` column with 5 clusters, and `n_genes` and `total_counts` columns. The file has `X_pca` with 50 dimensions and `X_umap` with 2.
