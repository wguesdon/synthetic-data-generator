# NanoString RCC files

This is an example of a description that a user gives to the agent. Every name and number is invented.

The customer sent one folder of nCounter RCC files, one file per sample, from a custom code set of 6 endogenous genes, 2 housekeeping genes, 3 positive controls and 2 negative controls.

There are 16 tumor samples: 8 responders and 8 non-responders. The analysis code reads the files with an RCC parser and normalizes to the positive controls and the housekeeping genes.

For the test data, plant a 2.5-fold rise of CXCL9 in the responders.
